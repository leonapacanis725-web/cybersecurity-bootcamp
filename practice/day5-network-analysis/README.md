# Day 5 - Network Traffic Analysis

## Objective
Practice collecting and examining network information
using Linux networking tools.

## Tools Used
- Linux
- tcpdump
- dig
- ping
- ip route

## Investigation Activities
- Identified network IP address.
- Examined default gateway.
- Queried DNS records.
- Tested network connectivity.
- Practiced packet capture.

## Evidence
See network-report.txt.

## Security Relevance
Network analysis helps security analysts understand
communication patterns and investigate suspicious activity.

## Limitations
The Linux environment runs inside a ChromeOS container.
Some host-level network traffic may not be visible.
