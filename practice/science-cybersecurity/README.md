# Science & Cybersecurity

## Project Overview
A simulated SSH login investigation demonstrating how the scientific method applies to cybersecurity analysis.

## Objectives
- Examine authentication log entries.
- Identify failed and successful login attempts.
- Compare source IP addresses and targeted usernames.
- Develop and evaluate a hypothesis using evidence.

## Tools Used
- Linux terminal
- grep
- awk
- sort
- uniq

## Key Findings
- 4 failed login attempts.
- 1 successful login.
- 3 failed attempts from one source IP.
- 4 different usernames targeted.

## Method
Applied the scientific method:
1. Observation
2. Question
3. Hypothesis
4. Testing
5. Analysis
6. Conclusion

## Data Limitations
All log entries and IP addresses are simulated. Findings do not establish a real attack.

## Skills Demonstrated
- Security log analysis
- Linux command-line investigation
- Evidence-based reasoning
- Scientific method in cybersecurity
