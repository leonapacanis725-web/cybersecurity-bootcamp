# Python Security Log Analyzer

## Project Overview
A beginner-friendly Python tool for analyzing
simulated Linux authentication logs.

## Features
- Detects failed login attempts
- Counts successful logins
- Groups failed attempts by source IP
- Flags IPs with 3 or more failed attempts

## Files
- security_log_analyzer.py
- sample_auth.log
- investigation_report.md

## Tools
- Python 3
- Linux terminal
- Python standard library

## Disclaimer
All sample authentication events are simulated.
Alerts indicate activity requiring investigation,
not confirmed malicious behavior.
