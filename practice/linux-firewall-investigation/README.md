
# Linux Firewall Configuration and Investigation

## Project Overview
A hands-on cybersecurity investigation examining Linux firewall configuration, UFW rules, IPv4 and IPv6 policies, and application profiles.

## Objectives
- Install and inspect UFW.
- Configure firewall rules.
- Examine firewall service status.
- Investigate IPv4 and IPv6 policies.
- Inspect application profiles and service ports.
- Identify the difference between configured and enforced firewall controls.

## Tools Used
- UFW
- iptables
- ip6tables
- systemctl
- grep
- Linux command line

## Investigation Highlights
- Installed and inspected UFW.
- Added three firewall rules.
- Identified that UFW remained inactive.
- Examined IPv4 and IPv6 default policies.
- Inspected SSH, HTTP, HTTPS, DNS, SMTP, IMAPS, and POP3S profiles.
- Identified a mismatch between saved firewall rules and active enforcement.
