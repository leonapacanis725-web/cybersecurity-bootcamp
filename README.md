# Cybersecurity Bootcamp Portfolio

A collection of hands-on cybersecurity exercises completed while developing practical Linux, networking, Python, Bash, and security investigation skills.

### Linux Security
- Linux Authentication Investigation
- Linux File Integrity Monitoring
- Linux Firewall Investigation
- Linux Process Investigation
- Linux Network Service Investigation
- Linux Permission Audit

### Network Analysis
- Network Traffic Analysis
- Linux Network Connectivity and DNS Investigation

### Security Monitoring and Log Analysis
- Linux Log Investigation
- Python Failed Login Analyzer
- Python Security Log Analyzer
- Science and Cybersecurity Investigation

### Automation and System Administration
- Cron Automation
- Linux System Health Investigation
- Automated Linux Incident Response Triage Tool

### Additional Learning
- Git and GitHub Notes
- IP Triage Script
- Automated Log Backup Script

## Capstone

The Day 14 capstone is a Bash-based Linux incident response triage tool. It collects system information, running processes, network sockets, persistence information, temporary-file activity, and authentication log findings. It generates SHA-256 hashes for collected evidence.

## Tools and Technologies

- Linux

- grep, awk, sort, uniq

## Learning Environment

Exercises were performed in a Debian-based Linux environment running through ChromeOS Crostini.

## Disclaimer

All exercises are for educational purposes. Simulated logs and training data are used where applicable. Findings represent practice investigations and should not be interpreted as confirmed real-world attacks.
